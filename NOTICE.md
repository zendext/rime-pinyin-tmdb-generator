# Data Notice

This project publishes generator source code only. It does not publish,
bundle, cache, or redistribute TMDb-derived titles, aliases, API responses,
or generated Rime dictionaries.

Users run the generator locally with their own TMDb API credentials. Any
generated `tmdb_hans.dict.yaml` or `tmdb_hant.dict.yaml` file is local output
created by the user.

TMDb API usage is subject to TMDb's own API and data licensing terms.
Review those terms before using or redistributing generated output.
